# हात्तीको गोबरको च्याउ (The Mushroom in Elephant Dung): fact / warning

Status (2026-11-27): script final, awaiting voiceover `inbox/elephant-dung-mushroom.mp3`. Length: ~66 words ≈ 33 s (Nepali ≈ 2 words/s; the real voice file rules).
Emotion: curiosity → gross-out → "oh no" → dark laugh. Twist: many wild mushrooms in Nepal are poisonous and some look exactly like these, so chasing "another world" can send you to the next one. Loop ending: no; ends on a tag CTA.

**Language: Nepali (Devanagari).** For Instagram / TikTok / Facebook. Register is "तपाईं" throughout (tag line uses "गर्नुस्").

## Rules for this reel
- This is a warning reel. Never show anyone eating mushrooms, preparing them, dosing, or "tripping" visuals that look fun. No how-to-find or how-to-identify detail anywhere (narration, overlays, caption, comments).
- **No rhinos.** Rhino dung + magic mushroom could not be verified (only seller pages). Animals shown: elephant, cow, buffalo only.
- Dung is cartoon dung (rounded brown piles, a few flies), not realistic. Mushrooms are small, generic brown-capped cartoon mushrooms; the poisonous look-alike gets a skull reveal.
- "Spores" are shown as tiny glowing specks; narration says "बीउ" (keep it, simple word).
- Facts fixed: 1,291 wild species recorded in Nepal, 100+ poisonous; don't add other numbers.
